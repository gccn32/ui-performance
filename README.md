# ui-performance

It is a simple project to compare a performance, amount of code written by developer and how easy is to write unit tests by developer for Angular, ReactJS and Typescript.

It consists of 3 projects:

- Just hello world app. Main component doesn't have any styles, HTML has only "Hello World" h1. It doesn't include router or store
- Loop performance. It is simple project which shows simple grid. User can navigate between 100, 1000 and 10000 lines in grid, simple sorting operations, change values of cells in grid, etc. All 3 projects (angular, reactjs and typescript) has similar component structure, store and router. Reducers, selectors and action are very similar or almost the same. Typescript uses simple handmade store and router.
- Gallery of images.
